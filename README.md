# AI Based Quiz Question Generator

## 📌 Project Overview

AI Based Quiz Question Generator ek web application hai jo kisi bhi **topic ya text** se automatically **quiz questions generate** karta hai.
Is project ka purpose teachers aur students ko quiz aur practice questions jaldi generate karne me help karna hai.

---

## 🚀 Features

* Topic ya text se automatic question generation
* Simple web interface
* Fast quiz generation
* Practice aur learning ke liye useful

---

## 🛠️ Technologies Used

* **Backend:** Python
* **Framework:** Flask
* **Frontend:** HTML, CSS, JavaScript
* **Other:** AI / NLP logic for question generation

## ▶️ How to Run the Project

### 1️⃣ Clone the repository

```
git clone https://github.com/gurjha14-lang/AI-based-quiz-question-generator.git
```

### 2️⃣ Go to the project folder

```
cd AI-based-quiz-question-generator
```

### 3️⃣ Install dependencies

```
pip install -r requirements.txt
```

### 4️⃣ Run the application

```
python app.py
```

### 5️⃣ Open in browser

```
http://127.0.0.1:5000
```
